# illenium-appearance

A modern appearance resource for FiveM supporting **ESX Legacy**, **QBCore**, and **ox_core**.

This fork improves the original project with an updated UI, enhanced ESX compatibility, configurable branding, and various performance and stability improvements.

---

## ✨ Features

- Modern Character Creator
- Clothing, Barber & Tattoo Shops
- Plastic Surgery
- Outfit Management
- Job & Gang Clothing
- Ped Support
- Hair Texture Support
- Clothing Restrictions
- Configurable UI Branding
- ESX Legacy, QBCore & ox_core Support

---

## 🚀 Improvements

- Redesigned user interface
- Configurable header and branding
- Improved ESX appearance synchronization
- Better outfit cache handling
- Improved logout cleanup
- Reduced unnecessary callbacks
- Performance and stability improvements

---

## ⚙️ Configuration

Customize the UI branding in `shared/config.lua`.

```lua
Config.HeaderTitle = "CHARACTER"
Config.HeaderSubtitle = "CUSTOMIZATION"
Config.LogoBrandText = "VERTEX CUSTOMS"
```

---

## 📦 Dependencies

- ox_lib
- oxmysql

---

## 📥 Installation

1. Place the resource in your `resources` folder.
2. Ensure the required dependencies are installed.
3. Add the resource to your `server.cfg`.

```cfg
ensure illenium-appearance
```
