# 🚀 T-Studio — Base Template V1

Bienvenue sur la première version publique de la **Base Template T-Studio**.

Cette base FiveM est conçue pour faciliter la création d'un serveur RolePlay sous **ESX Legacy**.

## ✨ Fonctionnalités

- ⚡ Base prête à configurer
- 🧩 Ressources organisées
- 🎮 Compatible ESX Legacy
- 💾 MySQL / MariaDB
- 🔧 Configuration facilement personnalisable
- 🇫🇷 Base pensée pour les projets francophones

## 📥 Installation

1. Téléchargez `Base-Template-T-Studio-V1.zip`
2. Décompressez l'archive
3. Importez le fichier SQL
4. Configurez votre `server.cfg`
5. Configurez votre connexion MySQL
6. Ajoutez votre clé de licence Cfx.re
7. Démarrez votre serveur

> ⚠️ Pensez à consulter le README.md avant l'installation.
